# Люди (people.promedia.report)

Компілятивні досьє на людей, про яких пише ПроМедіа: насамперед українських журналісток і журналістів, а також міжнародних журналістів і посадовців, про яких ми писали.

## Як це працює

- `people/data/<slug>.json` — одне досьє. Обов'язкові поля: `slug`, `name` (uk/en), `sort` (прізвище спершу, для абетки), `role`, `summary`, `bio.uk`, `sources`, `updated` (дата оновлення, YYYY-MM-DD).
- `people/article-people.json` — які люди згадані в яких новинах (slug новини → slug людей).
- Тег новини = ім'я та прізвище людини українською, як у `name.uk` (або одна з `aliases`). Такий тег на сайті новин англійською й кримськотатарською показується латиницею, а коли увімкнено сайт досьє, під текстом з'являється блок «Люди в матеріалі».
- `node people-site/build.mjs --index-only` оновлює `src/data/people-index.js` для новинного сайту — запускайте після кожної правки в `people/data`.
- Сайт збирає й розгортає GitHub Actions (`deploy-people-site.yml`) у воркер `promedia-people`. Фото шукаються автоматично у Вікіпедії/Вікісховищі лише з вільними ліцензіями; якщо їх немає — береться фото з інтерв'ю ПроМедіа (`photo.article`), інакше показуються ініціали.

## Правила

- Лише професійна, публічна інформація з відкритих джерел; кожне твердження має джерело в `sources`. Приватних даних (родина, адреси, здоров'я тощо) не публікуємо.
- Звинувачення без вироку суду — обережно й з атрибуцією, як у стандартах новин ПроМедіа.
- Після правки досьє оновлюйте `updated`.
- Додаючи нову новину про людину з досьє, додайте її ім'я в `tags` і slug новини в `article-people.json`.

## Субдомен

Субдомен `people.promedia.report` прив'язується до воркера `promedia-people` в Cloudflare (Workers → promedia-people → Domains & Routes). Після цього в `src/lib/people.js` треба вписати `PEOPLE_SITE_URL = "https://people.promedia.report"` — тоді на новинах з'явиться блок «Люди в матеріалі».
